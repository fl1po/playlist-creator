Import Local Data

Migrate your data from the local setup to this server.

How to export from local:
1. Make sure your local server is running
2. Open http://localhost:3005/api/export-data in your browser
3. Save the page as a .json file
4. Also save your config: http://localhost:3005/api/config (optional if you've already configured this server)
5. Drop the export file below
